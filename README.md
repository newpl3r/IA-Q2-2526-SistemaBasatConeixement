# Sistema Expert: "Al fin del mundo y más allá"

Aquest projecte implementa un Sistema Basat en el Coneixement (SBC) utilitzant **CLIPS** per a la generació d'itineraris de viatge personalitzats.

## Instruccions d'Execució

Per executar el sistema, segueix aquests passos:

1.  **Obre CLIPS**: Inicia l'entorn de desenvolupament de CLIPS.
2.  **Carrega els fitxers**: Assegura't que tots els fitxers (`classes.clp`, `main.clp` i el fitxer d'instàncies, si en tens un) estiguin a la mateixa carpeta. Executa les següents comandes a la consola de CLIPS:
    ```clips
    (load "classes.clp")
    (load "main.clp")
    ```
    *(Si tens un fitxer d'instàncies addicional, carrega'l també abans del següent pas).*

3.  **Inicia el sistema**:
    ```clips
    (reset)
    (run)
    ```

4.  **Interacció**: Un cop executat el comandament `(run)`, el sistema iniciarà el procés de recollida de dades. Respon a les preguntes que apareixeran a la consola per generar la teva recomanació de viatge.
